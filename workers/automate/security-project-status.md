# Project Status (Security)

## Escopo

A leitura operacional de `Security` acontece pela **task/issue** e pela evidencia da entrega (commits na `task-{id}` e **merge em `dev`**), nao por coluna do projeto e nao por PR do Developer.

PR do Developer **nao existe** no fluxo normal. Ver `agents/skills/shared/github/github-flow.md`.

## Entrada tipica

- existe label `agent:security`
- ha evidencia de entrega na task branch e/ou merge em **`dev`**
