# Security

Automacoes do agente de seguranca.

## Responsabilidades

- revisar tarefas associadas ao agent `Security`;
- reconhecer decisoes humanas estruturadas na issue e nos PRs vinculados;
- aguardar ou solicitar decisao estruturada de Security quando ainda nao houver evidencia suficiente;
- repassar a task para `Quality Assurance` ou `Developer` quando a decisao estiver clara.

## Regra operacional

Nao acione executor externo; a decisao deve ser registrada diretamente pelo papel responsavel em formato estruturado.
